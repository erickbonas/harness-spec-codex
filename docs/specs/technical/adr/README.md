> `Aceito` aqui; mudar uma decisão é escrever um ADR novo que substitui o antigo.

## Como adicionar

1. Próximo número: `NNNN-titulo-curto.md`, a partir de [\_modelo.md](_modelo.md).
2. Estados: `Proposto` · `Aceito` · `Substituído pelo ADR-NNNN` · `Obsoleto`.
3. Acrescente a linha no índice abaixo e em `docs/specs/index.md`.
